# Eddie Santos - Portfolio Website

A modern, responsive portfolio website built with SvelteKit 5, showcasing professional experience, technical skills, and projects.

🔗 **Live Site:** [esantosrcj.github.io](https://esantosrcj.github.io)

## Tech Stack

- **Framework:** SvelteKit 5 (with Svelte 5 runes)
- **Styling:** Tailwind CSS 4 + DaisyUI
- **Language:** TypeScript
- **Icons:** Lucide Icons
- **Build Tool:** Vite 7
- **Deployment:** GitHub Pages (static adapter)

## Features

- 📱 Fully responsive design
- 🎨 Modern UI with DaisyUI components
- 🌙 Professional portfolio layout
- ⚡ Fast performance with SvelteKit
- 📄 SEO optimized
- 🎯 Sections: About, Skills, Experience, Projects, Contact
